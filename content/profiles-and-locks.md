# Profiles, kids, and locks

A Plozz profile keeps your preferences, library choices, Home layout, and trackers. A **server user** controls server access and history; adding a Plozz profile does not create one.

## Choose who is watching

Use the profile header in **Settings** to switch. To edit on iPhone/iPad, hold a profile and choose **Edit Profile**, or use **More > Edit Profiles** in the picker.

From a non-Kids profile, open **Settings > Profiles > Add Profile** and name it. Choose servers, users, and libraries; on iPhone/iPad, choose **Done** to continue through Seerr, appearance, and optional lock setup. If interrupted, setup resumes when that profile opens.

**Automatically Sign In** restores verified Profile Lock or Plex PIN access at startup. Turn it off for startup PIN prompts; manual switches still check locks.

Each [Apple TV user](/apple-tv-profiles/) can remember a different Plozz profile.

## Add Plex Home profiles during setup

When **Add your Plex Home profiles?** appears, **Add all profiles** creates or reuses linked profiles, then opens **Choose your profile**. **Just me** opens **Choose your Plex user** instead. New profiles finish setup when first opened; Plex PIN checks still apply.

For children, configure [parental controls](/parental-controls/) separately.

## Choose a server user

1. Open **Settings > Libraries** for this Plozz profile and enable the server.
2. Open **Watching as**. On iPhone/iPad, it appears with multiple sign-ins; for Plex, tap the current user's name and avatar instead. Choose the viewer and complete any Plex PIN check.
3. For a missing sign-in, use **Add Another User** or **Add Another Plex Account** inside Watching as on Apple TV, or the mobile server controls. Confirm the identity and libraries.

Sign-ins are shared across this device's profiles. Disabled libraries hide browsing, not account-wide Continue Watching/Next Up. Set restrictions on the server.

Plex user choice sets whose Watchlist you use. **Don't use this server's watchlist** excludes its list, not playback; disable/re-enable the server in Libraries to reconsider.

## Lock a profile

In profile management, choose **Profile Lock** and confirm a four-digit PIN. Existing locks allow authorized change/removal.

Plozz can offer explicit, Plex-verified PIN reuse for protected Home users; otherwise the PINs remain separate. Profile locks do not replace server authentication. With iCloud Sync off, new locks apply only here.

## Set up a Kids profile safely

Follow [Parental controls](/parental-controls/) for the household PIN, source restrictions, playlist approvals, and device checks.

## Before deleting or resetting

Deleting a profile removes its preferences and server selections, not shared server sign-ins.

There is no in-app forgotten-PIN reset. If this profile is already unlocked for editing on another device, remove its **Profile Lock** there; iCloud Sync must be enabled to carry the change here.

See [Profiles and sync](/profiles-and-sync/) for transferable settings.
