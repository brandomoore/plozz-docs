# Create custom Home rows

Bring favorite collections, playlists, or libraries into one Home row. Save a filter for unwatched movies, for example, instead of setting it again whenever you browse.

## Choose the content

Select your Plozz profile first. Library choices need an enabled, accessible video library; music libraries are excluded. Home history feeds can include titles from libraries hidden from browsing.

1. Open **Settings > Screens & Navigation > Home > Rows > Add row > Custom row**.
2. Open **Content**. Choose **Collections** or **Playlists** to select named lists from an available **Source**. Choose **Done** to return.
3. You can also select Home feeds, whole libraries, or their recommendation rows directly in Content. Select several to combine them. **Selected** shows your choices; its remove buttons undo selections.
4. Choose **Done** to return to the row editor.

Lists and recommendations depend on your provider and server user. This does not create a server playlist, move files, or grant access to another account's media.

## Set the order and appearance

The editor presents these choices in order:

- **Name**: leave it blank to use the selected content's names.
- **Sort**: keep **Source order**, or choose **Name**, **Date Added**, **Release Date**, or **Runtime**, then **Order**. Source order takes turns adding titles from each source; matching copies can share a card. Date Added uses save dates for a row containing only **Watchlist**.
- **Filter**: choose **Media** and **Watch status** together. **Clear Filters** resets both. Filtering or sorting can need the full list to load, so large libraries take longer.
- **Layout**: choose **Posters**, **Landscape**, or **Featured**. Landscape also offers **Logo**, initially **Off**, for title logos over the artwork.

The preview below shows the result without opening or playing its cards. Choose **Add to Home** to save; on iPhone/iPad, use the checkmark with that label.

## Change or repair a row

Reopen it under **Home > Rows**; on iPhone/iPad, you can also hold its Home heading and choose **Edit**. Existing Apple TV rows save automatically; names save when the keyboard closes, including with Back. Mobile edits need the **Save changes** checkmark. **Remove from Home** removes the row, not its media.

For **Unavailable source**, check the enabled library and server user, then reselect content if needed. Use **Retry** for loading errors. If saving fails, retry the save; existing Apple TV rows offer Retry. An empty preview can mean nothing matches your filter.

To explore more titles, [open the row's larger grid](/browse-home-rows/). Changes there are temporary; edit the row to change Home.
