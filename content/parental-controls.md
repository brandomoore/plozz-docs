# Parental controls

Plozz plays media from sources you connect. For children, combine a **Kids Profile** and **Parental PIN** with suitable content restrictions on those sources.

## Set up a Kids profile

1. From a non-Kids profile, open **Settings > Profiles**. Add a Kids profile or enable **Kids Profile** in an existing profile's management settings.
2. Choose a restricted **server user** and suitable libraries for that profile. A Plozz profile does not create a server account or change its permissions.
3. Create a household **Parental PIN** in **Settings**. This protects restricted settings and leaving Kids profiles; keep it separate from PINs a child knows.
4. If using [Seerr requests](/media-requests/), link the profile to a restricted Seerr user instead of an unrestricted administrator.

## What the controls do

Kids profiles disable external Discovery recommendations. With a Parental PIN, changes to restricted settings and leaving the Kids profile require authorization.

Without a Parental PIN, restricted settings and profile switching remain available, and Seerr's Kids admin-request block is not enforced. Removing the PIN does not turn Kids profiles off.

A [Profile Lock](/profiles-and-locks/#lock-a-profile) protects entry into one profile. It is not a substitute for the household Parental PIN or server permissions.

## Choose suitable media sources

> [!IMPORTANT]
> Kids profiles do not add an app-wide maturity filter. Library content follows the connected server user's restrictions, not an automatic inspection of every video.

Set age/content restrictions on the media server itself. Hiding a library or Home row is not access control: account-wide Continue Watching and Next Up can still contain titles from hidden libraries.

For [network shares](/network-shares/), choose folders containing only suitable media; there is no media-server user enforcing maturity restrictions.

For playlist sources, follow [Approve playlist sources for Kids](/live-tv/#approve-playlist-sources-for-kids). Approval allows the whole source, not age-filtered programs, and stays on that device. Review the channels before approving.

## Check each device

Switch into the Kids profile and check its libraries, Continue Watching, Live TV, and access to restricted settings before handing over the device. Review [automatic sign-in](/profiles-and-locks/#choose-who-is-watching) so a previously authorized adult profile does not reopen unexpectedly.

Recheck restrictions after changing a server user, source, or profile. For lock changes and recovery limits, see [Profiles, kids, and locks](/profiles-and-locks/).
